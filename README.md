# Project 1 — Linux Server Operations & Troubleshooting

## Project Overview

**Ubuntu Server | VMware | SSH | Linux Administration | Troubleshooting**

A hands-on Linux Server administration and troubleshooting project designed to simulate real-world Infrastructure Operations and Data Center environments.

- Built and administered a multi-VM Ubuntu Server home lab using VMware.
- Practised Linux user and group administration, file permissions, ownership and access control.
- Performed package management, networking configuration and SSH-based remote administration.
- Managed Linux services and systemd units.
- Configured and tested scheduled tasks using cron.
- Investigated CPU, memory, disk utilisation, running processes and system load using standard Linux troubleshooting tools.
- Analysed system and boot logs using "journalctl" to identify warnings, errors and service-related issues.
- Performed remote server administration and troubleshooting over SSH between lab hosts.
- Investigated and resolved Linux permission and access issues by analysing ownership, directory permissions and group membership.
- Practised storage, backup and restore fundamentals.
- Applied a structured troubleshooting methodology:

**Identify → Investigate → Root Cause → Fix → Verify → Document**

- Documented technical procedures, commands, evidence, troubleshooting results and lessons learned in a professional GitHub portfolio.

## Troubleshooting Methodology

The project follows a structured infrastructure troubleshooting process:

1. **Identify** — Confirm the reported problem and symptoms.
2. **Investigate** — Collect system information, logs and command outputs.
3. **Analyse** — Narrow down the possible causes.
4. **Determine Root Cause** — Identify the actual cause of the failure.
5. **Fix** — Apply the appropriate corrective action.
6. **Verify** — Confirm that the system and service are functioning correctly.
7. **Document** — Record the incident, root cause, fix, verification and lessons learned.
