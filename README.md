# Linux Server Home Lab

## Overview

This repository documents my hands-on Linux Server administration practice using Ubuntu Server and Oracle VirtualBox.

The purpose of this project is to develop practical Linux administration skills required for IT Support, Server Administration, and Data Center Operations roles.

## Lab Environment

- Oracle VirtualBox
- Ubuntu Server

## Completed Labs

- Ubuntu Server Installation
- SSH Configuration
- Linux User Management
- File & Directory Management
- File Operations
- Server Boot Troubleshooting
- Linux Server Mode Management
- systemd Administration
- Maintenance Shutdown Control
